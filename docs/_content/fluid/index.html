Open source, MIT licensed

Liquid templates for .NET. Fast, safe, yours.

Fluid parses and renders Liquid, the template language of Shopify, with few allocations. Templates only read the data you allow, so your users can write them, and every filter, tag and operator can be extended.

Get started Try it in the browser
$ dotnet add package Fluid.Core

products.liquid

{% raw %}
<ul>
{% for product in products %}
  <li>{{ product.name | upcase }}
    {{ product.price | money }}
  </li>
{% endfor %}
</ul>
{% endraw %}

Output

<ul>
  <li>APPLE $329.00</li>
  <li>ORANGE $25.00</li>
  <li>BANANA $99.00</li>
</ul>

Features

Everything Liquid, and what .NET applications need

  1. 01

    Shopify compatible

    Reads templates like Shopify Liquid, verified with the Golden Liquid test suite and against Shopify's own engine.

    Liquid syntax
  2. 02

    Fast, few allocations

    A hand-written parser, no regular expressions, and a synchronous fast path for async rendering.

    Benchmarks
  3. 03

    Secure by design

    Templates read an allow-listed model, and limits bound recursion, steps, output size and collections.

    Security
  4. 04

    Async everything

    Filters, member accessors and file providers can be asynchronous, and renderings can be cancelled.

    Parsing and rendering
  5. 05

    Your own grammar

    Register tags, blocks, operators and functions, with any parser built from Parlot combinators.

    Extending the grammar
  6. 06

    Any .NET model

    POCOs, dictionaries, JsonNode and custom values, with value converters and naming policies.

    Models and values
  7. 07

    Source generators

    Read models without reflection for NativeAOT, or compile .liquid files into C# at build time.

    Compiled templates
  8. 08

    ASP.NET Core views

    Liquid views with layouts, sections and _ViewStart files, for MVC or Minimal APIs.

    View engines

Three lines

Parse once, render many times

A parser and the options are created once and shared by the whole application. Parsed templates are thread-safe and can be cached, and each rendering gets its own context.

Getting started
{% raw %}
var parser = new FluidParser();

var template = parser.Parse("Hello {{ name | capitalize }}!");

var context = new TemplateContext(new { name = "world" });

Console.WriteLine(await template.RenderAsync(context));
// Hello World!
{% endraw %}
